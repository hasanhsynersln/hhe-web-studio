# HHE Web Studio — Aşama 9

Bu paket, HHE Web Studio ana sayfasını ve dört konsept demo sitesini içerir.

## Görsel varlıklar
- `assets/villa-hero.jpg`: Villa demosu ana görseli
- `assets/*-preview.jpg`: Ana sayfadaki sektör kartları ve ilgili demo hero görselleri
- `assets/hhe-logo.svg`, `assets/hhe-mark.svg`: Marka logoları

## Yapı
- `index.html`: HHE Web Studio ana sayfası
- `demos/villa/index.html`: The Villa Collection
- `demos/cafe/index.html`: Roast & Root
- `demos/auto/index.html`: FORM Motor
- `demos/beauty/index.html`: Atelier Beauté
- `gizlilik.html`, `kullanim.html`: Taslak yasal bilgilendirme sayfaları

Demolar konsept çalışmadır; gerçek müşteri referansı değildir. Formlar sunucuya veri kaydetmez. Yayına almadan önce gizlilik ve kullanım metinleri hukuki incelemeden geçirilmelidir.
